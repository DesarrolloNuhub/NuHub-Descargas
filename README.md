# NuHub para Revit · Descargas

Herramientas para la gestión y la calidad BIM dentro de Autodesk Revit.

**[⬇ Descargar la última versión](https://github.com/DesarrolloNuhub/NuHub-Descargas/releases/latest)** · [Manual de uso](https://desarrollonuhub.github.io/NuHub-Manual/) · Soporte: Desarrollo@nuhub.com.co

## Qué incluye

| Panel | Plugins |
|---|---|
| Calidad BIM | Auditor · Cantidades · Matriz LOIN |
| Gestión BIM | Colisiones · Revisor · Editar Información · Renombrar · Plantillas · Parámetros · Exportadores |
| Externos | Validador · Externos |
| NuHub | Cuenta NuHub (sesión, plan, actualizaciones y soporte) |

## Requisitos

- Windows 10 u 11 de 64 bits.
- Autodesk Revit 2024, 2025 o 2026 (el instalador instala en las versiones que encuentre).
- Conexión a internet y una cuenta NuHub (se crea gratis desde el plugin Cuenta, con período de prueba).

## Cómo instalar

1. En [la última versión](https://github.com/DesarrolloNuhub/NuHub-Descargas/releases/latest), en **Assets**, descargue `NuHub-Instalador-V.x.x.exe`.
2. Cierre Revit y ejecute el instalador.
   Mientras NuHub está en versión de prueba, Windows puede mostrar «Windows protegió su PC»: elija **Más información → Ejecutar de todas formas**.
3. Elija **Solo para mí** (no pide permisos de administrador) o **Para todos los usuarios**, y la **Suite completa**, un paquete o los plugins que quiera.
4. Lea y acepte el contrato de licencia.
5. Abra Revit: en el aviso de cada complemento elija **Cargar siempre**. Encontrará la pestaña **NuHub**.
6. Abra **Cuenta** e inicie sesión o pulse **Crear cuenta**.

Para desinstalar: Configuración de Windows → Aplicaciones → **NuHub para Revit** → Desinstalar.
Sus configuraciones guardadas no se borran.

## Privacidad

NuHub no envía sus modelos ni la información de sus proyectos a ningún servidor: solo valida la licencia de su cuenta.
